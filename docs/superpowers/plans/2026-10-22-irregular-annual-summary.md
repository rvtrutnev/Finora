# Irregular annual summary implementation plan

Согласовано пользователем: рядом с резервом выбранного месяца показать «Всего в год», равное этому резерву × 12, отдельно по каждой валюте. Это годовая стоимость текущего плана, не фактические платежи календарного года. Оформление Classic/Pixel сохраняется; при ошибке загрузки не показывать нулевые итоги. Без публикации.

**Goal:** Общий годовой итог рядом с месячным резервом.
**Architecture:** Использовать существующий результат FinoraPlanning.reserves; бюджетные записи и Supabase не менять.
**Tech Stack:** Vanilla JS, HTML, node:test.
