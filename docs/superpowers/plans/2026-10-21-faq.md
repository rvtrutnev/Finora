# FAQ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Контекстная русскоязычная справка по восьми разделам без потери пользовательских черновиков.

**Architecture:** Отдельные данные FAQ и контроллер нативного dialog. Приложение передаёт идентификатор активной страницы; справка не вызывает showPage и не обращается к Supabase. Нативный модальный диалог обеспечивает блокировку фонового интерфейса и клавиатурного фокуса.

**Tech Stack:** Vanilla JavaScript, HTML dialog, существующие CSS-токены Classic/Pixel, node:test.

## Global Constraints

- Согласованная спецификация: docs/superpowers/specs/2026-10-21-faq-design.md.
- Все восемь разделов, русский язык, отсутствие личных финансовых данных в примерах.
- Не менять расчёты, импорт, авторизацию и пользовательские данные.
- Не публиковать и не выполнять push без отдельного разрешения.
- Сохранить существующие незакоммиченные .impeccable/ и .superpowers/.

## Task 2: Панель, интеграция и доступность

**Files:** Create js/faq-ui.js, tests/faq-ui.test.mjs; modify index.html, styles/themes.css, sw.js, tests/service-worker.test.mjs.

**Interfaces:** FinoraFAQ.create({document,content}) возвращает {open(sectionId),close()}. Контроллер создаёт dialog один раз, безопасно наполняет его через textContent/createElement. При повторном открытии выбирает текущий раздел. Сохраняет прежний overflow body и элемент возврата фокуса.

- [ ] Написать тесты open('import'), выбора другого раздела, close(), повторного открытия, неизвестного раздела, Escape/события cancel и закрытия по фону. Использовать минимальную DOM-фикстуру, проверяющую состояние реального контроллера, а не вызовы моков. Событие close должно восстанавливать overflow и фокус.

```js
const faq = ui.create({document: fixture.document, content});
faq.open('import');
assert.equal(fixture.dialog.open, true);
assert.equal(fixture.document.querySelector('#faq-section-title').textContent, 'Импорт');
faq.close();
assert.equal(fixture.dialog.open, false);
assert.equal(fixture.document.body.style.overflow, '');
assert.equal(fixture.document.activeElement, fixture.opener);
```

- [ ] Запустить тест до реализации; подтвердить ожидаемое падение. Реализовать dialog.showModal(), кнопку закрытия, select с доступным названием для выбора раздела и прокручиваемую статью. Проверка клика по фону должна учитывать координаты относительно getBoundingClientRect, чтобы клик внутри пустого места панели не закрывал её.
- [ ] Подключить модули после import-ui.js; добавить кнопку рядом с nav-settings. Определять активный раздел из .page.active без изменения showPage:


- [ ] Закрывать панель в существующем обработчике изменения владельца сессии, а не только при нажатии signOut. Не выполнять финансовых запросов.
- [ ] Стилизовать панель на токенах --color-surface, --color-text-control, --color-border, --color-action. На desktop ширина min(560px,100vw), справа, высота 100dvh; до 640px полная ширина. Видимые focus-visible, область кнопок не меньше 44px, основной текст 16px и line-height 1.6. Применить действующие пиксельные токены; основной текст оставлять читаемым.
