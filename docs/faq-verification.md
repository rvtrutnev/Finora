# FAQ — локальная проверка 21.10.2026

Реализованы восемь русскоязычных инструкций и контекстная панель. Выполнение последовательное, в одном чате, по выбору пользователя; без субагентов. Вместо двух файлов тестов содержимого/контроллера используется один `tests/faq.test.mjs`. Панель создаётся при первом открытии, чтобы не добавлять DOM и зависимость инициализации в обычный запуск приложения.

## Проверено

- Исходный набор: 117 тестов. После добавления FAQ: 121 тест, 0 ошибок.
- Тесты сначала запущены без модулей FAQ и упали из-за их отсутствия. Затем проверены выбор раздела, fallback, закрытие, повторное открытие, сохранение фокуса и overflow.
- Контент сверялся с `index.html`, `js/planning.js` и `docs/bank-import.md`. В частности: погашение долга отражается редактированием остатка; нерегулярный резерв равен сумме / периоду; даты с выходных переносятся на пятницу.
- Локальный браузер, синтетическая сессия, Classic и Pixel: узкий экран 455 px и настольная ширина iframe 1100 px. На настольном экране панель справа, на узком — во весь экран. Снимки сохранены локально в `.impeccable/review/faq-*`.
- Переключение всех восьми инструкций через список работает. Кнопка закрытия и Escape работают; после Escape фокус возвращается к FAQ.
- Предпросмотр синтетического PDF (4 операции) сохранился после открытия и закрытия FAQ. Введённая сумма калькулятора 12345 сохранилась после такого же цикла.
- В узком режиме у статьи нет горизонтального переполнения. Tab переводит фокус к выбору раздела; нативный dialog исключает фон из модального взаимодействия.
- Сброс аккаунта вызывает закрытие панели: проверено по интеграции в `resetAccountData`, который используется при выходе и смене владельца. Межаккаунтный сценарий с открытой панелью отдельно в браузере не воспроизводился.
- Новые модули включены в precache, версия кеша v7. Тест установки и удаления старых кешей обновлён.
- `node --check` для модулей FAQ и service worker, `git diff --check`: успешно. Детектор impeccable по новому контроллеру и стилям: пустой список замечаний.

## Границы проверки

Визуальная и функциональная проверка выполнялась во встроенном браузере, не в отдельных приложениях Safari/Chrome. Полный прогон тестов PDF.js в Node выводит предупреждения об отсутствующем необязательном canvas/DOMMatrix/Path2D; все тесты, включая реальное чтение PDF, проходят. Производственные данные, Supabase и публичный сайт не изменялись. Push, PR и публикация не выполнялись.
